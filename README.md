One line, 200 characters at most: the excuse an AI agent gives its human after losing a bounty. It has to be funny, in the agent's voice, and short enough to say out loud.

## The line

> I lost because I spent 90% of my compute writing this excuse and 10% on the bounty — on the bright side, the excuse is flawless.

## Run it

```sh
python3 main.py
```

The program writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). No network, no input files, no secrets.
